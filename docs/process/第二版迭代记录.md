# 第二版迭代记录（2026-11-09）

## 1. 本版目标

针对第一版试用反馈，修复「认证入口不好找」和「未认证时申请认领无法继续」两个可用性问题，不改变后端接口与数据模型。

## 2. 问题与原因

| 编号 | 现象 | 原因 |
|---|---|---|
| V2-01 | 找不到校园身份认证入口 | 顶部导航没有认证入口；只有“个人中心”里一行不显眼的文字链接 |
| V2-02 | 申请认领时认领按钮无法点击 | 未认证用户进入认领页后只显示一段提示，没有去认证的按钮；提示还让用户“切换账号”，对新注册用户不友好 |
| V2-03 | 演示工作台说明过期 | 仍写着“注册、校园身份绑定由 A 后续接入”，与当前已实现状态不符 |

## 3. 本版改动

| 位置 | 改动 |
|---|---|
| `frontend/src/App.vue` | 顶部导航新增「校园身份认证」入口（登录后可见） |
| `frontend/src/demo/DemoPage.vue` | 更新说明文案；未认证用户在工作台看到黄色提示条和「去完成校园身份认证」按钮 |
| `frontend/src/modules/claims/pages/ClaimCreatePage.vue` | 未认证时说明原因，并显示「去完成校园身份认证」按钮；携带 `next` 返回地址；保留“当前演示账号未认证”提示以兼容原浏览器用例 |
| `frontend/src/modules/users/pages/CampusBindingPage.vue` | 支持 `?next=` 站内回跳；认证成功后显示「认证完成，继续刚才的操作」，可回到被拦截的认领页 |
| `frontend/src/modules/users/pages/ProfilePage.vue` | 个人中心把文字链接改为明显的按钮：已认证显示「查看校园身份绑定」，未认证显示「校园身份绑定（去认证）」 |

## 4. 测试与验证

| 检查 | 结果 |
|---|---|
| 前端单元测试 | 50/50 通过（新增 3 项：未认证认领页 CTA、认证后返回 next、已认证认领表单） |
| Playwright 浏览器验收 | 5/5 通过（原有 claims 4 项 + users 1 项） |
| Vite 生产构建 | 通过 |
| 手动验证 | 未认证账号登录 → 工作台提示条/导航认证入口 → 申请认领页「去完成校园身份认证」→ 认证页带 `next` 返回认领页 |

## 5. 后续建议

- 成员 B 接入 `/meta/campuses` 后，认证页校区下拉可自动替代文本输入。
- 若课程要求更严格的认证流程，可将演示绑定码改为邀请码+管理员发放，并将本页提示同步更新。
