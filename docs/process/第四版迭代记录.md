## 3. 本版后的启动方式

### 3.1 两个终端 + 仓库脚本（推荐）

```powershell
Set-Location 'C:\Users\haoha_99nt8ny\Desktop\校园失物招领系统'
# 终端 1
powershell -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1
# 终端 2
powershell -ExecutionPolicy Bypass -File .\scripts\start-frontend.ps1
```

### 3.2 直接命令

```powershell
# 终端 1（项目根目录）
.\.venv\Scripts\python.exe backend\manage.py runserver 127.0.0.1:8000

# 终端 2
Set-Location frontend
npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

### 3.3 PyCharm 运行配置

PyCharm 运行下拉框选择「后端 Django (8000)」「前端 Vite (5173)」；工程配置 `.idea/`、`.run/`、`.iml` 已在本机生成，不属于 `.bat` 启动器。

停止：在对应终端 `Ctrl+C`；端口残留时查看并结束占用进程：

```powershell
Get-NetTCPConnection -LocalPort 8000,5173 -State Listen | Select-Object LocalPort,OwningProcess
```
